# Project Maintenance

- Read `docs/ADDING_A_COURSE.md` before adding or restructuring a course. Keep published knowledge IDs and existing learning records stable.
- Read and follow `docs/MAP_POLICY.md` for every map, map source, boundary, place name, or new course containing geographic material.
- Maps are teaching illustrations, not statements of sovereignty. Mark potentially disputed maps with `Geography.requiresDisclaimer`; only courses containing a marked map show the shared Chinese display-only, nonpolitical, peace declaration on their homepages. Use the same base declaration without region-specific additions, and never insert it into exercises. Courses such as Thai do not need a declaration.
- India maps use the explicitly selected, versioned China POV source in `scripts/build-india-map.mjs`. Do not replace it with the default Natural Earth layer, an India POV layer, or an unreviewed online basemap.
- Keep source versions, licenses, adapted GeoJSON, projection metadata, and rebuild scripts together. Do not describe illustrative boundaries as government-reviewed maps.
- Language facts need traceable research. Never label automated tests or manually authored IPA as independent native-speaker review.
