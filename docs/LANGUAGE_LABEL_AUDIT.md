# 分支语言角标核查

日期：2026-11-01。当前实际多语言课程只有孟加拉语主线与阿萨姆语分支；其他课程不凭脚本名称虚构语言分支。独立母语全量审读尚未取得。

## 显示原则

`languageIds` 代表这条**完整教学知识**适用的语言，不是“这个 Unicode 字符只在哪个语言出现”。共用字形不足以共用读音、转写或解释；有差异时拆知识 ID。角标用于区分此处采用的语言读法，不宣称文字或词只能属于某一语言。

`contrastLanguageLabel` 统一用于配对题、两个 Rush 与图鉴：

- 只有一种或未设置分支语言的课程不显示角标。
- 明确覆盖课程全部已注册语言的知识不显示角标，保留原归属和语言筛选能力。
- 只适用部分语言的知识保留对应语言名；即使当前筛选只选一种语言，也不把“筛选范围”误当作知识本身变成共用。
- 新增第三种语言后，仅覆盖原两种语言的知识仍显示两种归属；不会因“有多个 languageIds”就误当作全部共用。
- 不按字形、拉丁转写或 IPA 相等自动合并条目；同音也可能有不同条件与转写。

## 数据核查

共用集合逐项按规范表、所教宽式音值和说明核对。保留共用的 43 项：

- 辅音：ক、খ、গ、ঘ、ঙ、ন、ম、প、ফ、ব、ভ、ল、ঞ、ণ、হ。本课保留传统送气/气声宽式值，具体词变体仍分语言；ঞ 的说明去掉了会被误套到阿萨姆语合字的单一 /ndʒ/ 示例。
- 元音与附标：অ、আ、ই、ঈ、উ、ঊ、া、ি、ী、ু、ূ、ঐ、ঔ、ৈ、ৌ。这些是卡片限定的共用宽式值，不是对所有词、所有口音的替换规则。
- 鼻音/鼻化/滑音：ং、ঁ、য়；整词实际实现、鼻化强弱与合字行为仍按语言核对。য় 的 /j/ 卡限定为两语言都出现的值，明确阿萨姆语该音多见英语借词，母语词还可对应 /i/、/e/；不是把 /j/ 当作 তিনিচুকীয়া 等词的默认替换音。
- 十个共用数字字形及数值；不声称字母名、数字词发音也相同。

**修正错误共用的 4 项**：

| 字形 | 孟加拉语主线 ID / 教学值 | 阿萨姆语新 ID / 教学值 |
| --- | --- | --- |
| এ | bn-e /e/，说明条件变体 | as-e /ɛ/，说明 /ɛ~e/ |
| ◌ে | bn-e-sign /e/ | as-e-sign /ɛ/，说明 /ɛ~e/ |
| ও | bn-o /o/ | as-o /ʊ/ |
| ◌ো | bn-o-sign /o/ | as-o-sign /ʊ/ |

来源是 Appen/LDC 的阿萨姆语采集说明 §7（页 6–9），而不是依据英语地图名猜音。其内部可逆转写不是课程方案，字母转写继续以阿萨姆语 UNGEGN 表为准。新卡进入分支第 4 单元；相关分支城市先修改指向分支元音卡，不再借孟加拉语单元音作默认先修。相邻元音形成双元音时仍按整词核对，不全局替换地名音值。

已存在的差异项继续独立：ৰ/ৱ，শ/ষ/স，চ/ছ，জ/ঝ/য，齿音与传统卷舌拼写、r 类、ঋ/ৃ、含 ৰ 的合字，以及两语言的整词、规则和地名。本轮没有因为单字形“看起来相同”就扩大共享规则、合字或整词范围。

## 兼容与验证

不删除、更名或重置任何已发布知识 ID、FSRS、旧单元记录或语言筛选。旧 bn-e 等保留为孟加拉语知识；新增 as-e 等需要在分支中学习。以前完成过分支第 4 单元的用户会看到新增目标未学，不伪造它们的成绩。

测试包括四种筛选组合、全共用/部分共用/第三语言情况、分支从零走通、两个 Rush、主线与分支元音先修，以及宽窄屏配对题：共用 ক 无角标，孟加拉语 এ 与阿萨姆语 ও 分别保留角标。同形异音的两条 এ 不强塞同一棋盘，维持原先唯一配对的去歧义约束。
