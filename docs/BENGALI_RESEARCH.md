# 孟加拉语文字课程研究与审校记录

核对日期：2026-10-22。课程文件：`src/data/bengali.ts`；逐词证据：`BENGALI_WORD_AUDIT.json`。

## 目标与边界

目标是让 GeoGuessr 学习者从原文辨认字音、街景成分和地图名称，不是覆盖所有孟加拉语方言、全部梵语专用字形或完整口语训练。孟加拉文用于孟加拉国，也用于印度部分地区；文字线索不能单独证明国家。阿萨姆语共用近亲文字而有额外字母和不同音值，不包含在此课。

课程共 19 个主线单元（18 个编写单元及模板自动生成的词汇补充）、95 个非词汇知识、29 个主线词和 12 个城市额外词：

| 内容 | 数量 | 取舍 |
| --- | --- | --- |
| 抽象规则 | 9 | 固有元音、附标顺序、元音脱落、hasanta、鼻音符号、স、ফলা、借词、地图名 |
| 基本辅音与特殊尾/鼻音符号 | 37 | 现代常用字母，加 ড়、ঢ়、য়、ৎ、ং；不假装每字只对应一个不变音值 |
| 常见合字 | 17 | 手工限定音值和条件，不自动生成任意组合 |
| 独立元音与附标 | 22 | 现代常见结构，包括 ঐ/ঔ、ঋ 及 য-ফলা + া 的条件模板 |
| 数字 | 10 | ০–৯ 的字形与数值；不伪造数字词发音 |
| 主线词 | 29 | 村镇、市场、道路、桥河、学校、医疗、行政、方位、交通、国家与宗教设施 |
| 城市额外词 | 12 | 4 组，每城有原文、实际读音、惯用拼名和近似位置 |

主线词例：গ্রাম、নগর、পাড়া、বাজার、রাস্তা、সড়ক、সেতু、নদী、স্কুল、হাসপাতাল、থানা、জেলা、বিভাগ、উত্তর、দক্ষিণ、পূর্ব、পশ্চিম、বাংলাদেশ。它们是实际词，不是从辅音替换器“生成”的假词。

## 记音决策

### 字形与读音分离

辅音卡 `ক → k /k/` 表示辅音部分，不是字母名，也不表示实际词中永远没有固有元音。开头立即说明 /ɔ~o/ 及附标替换；`কি` 左侧的 i 附标在发音中仍跟在辅音之后。

没有 hasanta 不保证读出元音，词尾也不总删元音。`নগর /nɔɡoɾ/` 的两个隐含元音不同，末尾 র 无元音；`পূর্ব /puɾbo/` 反而保留末尾 /o/。不允许用统一“最后删一个元音”算法猜答案。

### 教学转写

使用明示的读音转写，而不是可逆字母编码：

| 转写 | 用途 |
| --- | --- |
| `ô`，可输入 `aw` | /ɔ/；严格区别于 `o` /o/ |
| `ch` / `chh` | /tʃ/ / /tʃʰ/ |
| `j` / `jh` | /dʒ/ / /dʒʱ/ |
| `sh` | /ʃ/ |
| `kh th ph` 等 | 送气音，不是辅音加独立 h，也不是英语 digraph |
| `t d n r` 等 | 为易输入而合并部分舌位差别，IPA 和说明保留区别 |

不标 `officialRomanizationName`，不把 ALA-LC 字母表或英语地图惯用名冒充此读音系统。`Chattogram / Chittagong`、`Cumilla / Comilla`、`Jashore / Jessore` 等另列 `conventionalNames`，可输入但不改变主教学读音。常见地图成分 Nagar、Bazar、Setu、Dakshin 等也与读音分栏。

### IPA 的宽式与地区边界

- 使用传统宽式 /ʈ ɖ tʃ dʒ ɾ ɽ/ 保持书写系列的教学可辨认性；不声称它就是所有孟加拉国说话人的严式发音。
- Khan 的描述显示，孟加拉国后部塞音常更靠前、塞擦音可更靠前、r 常为 [ɹ]，元音鼻化对立弱于传统描述。相应说明写在课程参考和知识条目里。
- 现代 ই/ঈ、উ/ঊ 通常不构成音位性长短对立，不因传统“长元音”名称就强制加 /ː/。实际重叠辅音仍保留长音，例如 ত্ত /t̪ː/。
- জ/য、ন/ণ、শ/ষ 等常合流；同音目标不能竞争唯一反向答案或同一配对板。স 在部分词中为 /s/，不是“所有 s 字母都统一替换为 sh”。
- ফ、ভ 的传统 /pʰ bʱ/ 与现代 /f v/ 实现分开说明；不会自动把所有词统一替换。
- ক্ষ、জ্ঞ 和 ফলা 有位置与词汇条件。卡片明确限定词内常见值，词首或其他语境另作说明，不开启通用 `composition`。
- /æ/ 条件模板 `◌্যা` 只解释词首辅音后的常见用途，不声称所有 য-ফলা 都读 /æ/ 或 /j/。

## 逐词审校

`BENGALI_WORD_AUDIT.json` 共 41 词，逐项记录原文、中文义、主转写、采用 IPA、原词条 IPA 与转写、固定词条版本、前置知识、完整片段、地图名和位置。

36 词有词条列出的 IPA；比较时只做以下公开的记号归一：

1. 去掉音标括号、常规重音、音节分隔、连音弧和半长符号。
2. 来源普通 `r` 按本课记为 `ɾ`。
3. `ময়মনসিংহ` 的来源括号表示词尾 ho 可省，本课显式选保留 ho 的列出变体。

不消除元音音质、送气、辅音长短或辅音差别来“凑通过”。以 ঐ/ঔ 的教学音值等知识条目为例，独立音值仍由文字/语音学研究支持，不受词条比较脚本替代。

以下 5 词的词条没有独立 IPA，证据为词条转写结合已核对的标准音值，**仍待独立语言审读**：

| 词 | 采用值 | 证据限制 |
| --- | --- | --- |
| সেতু | /ʃet̪u/ | śetu 转写，不标“独立 IPA 审校通过” |
| খুলনা | /kʰulna/ | khulna 转写，城市而非整个同名专区 |
| রাজশাহী | /ɾadʒʃahi/ | rajśahi 转写；词中 জ 后不另加元音 |
| বরিশাল | /boɾiʃal/ | boriśal 转写；保留 Barisal / Barishal 名称 |
| কুমিল্লা | /kumilːa/ | kumilla 转写；辅音重叠，不虚构元音长度 |

全部条目的 `independentNativeReview` 均为 `false`。程序检查只证明结构、来源追踪和列出的记号比较结果，不能证明中文解释或发音经过语言专家独立认证。没有声称内容“完美”或母语审定。

## 教学与模板整合

阶段由辅音/元音形态走向实际词，再进入常见合字、数字与地图：

1. 单元 1–2：固有元音、附标和独立元音，开头就区分字母名与词内辅音。
2. 单元 3–8：按发音部位组织字母和常见附标，逐步穿插先修已完成的真实词。
3. 单元 9–11：把元音脱落、স、hasanta、鼻音和双元音放回实际结构。
4. 单元 12–15：র 的两种位置、重叠辅音、鼻音群、街景常见复杂合字、ফলা 和借词。
5. 单元 16–18：门牌/距离数字、文字国家线索与地图旧新拼名。
6. 模板词汇补充：集中补齐尚未练习的主线词；不把早已练过的词重当新词。

规则首次只做一次独立判断；通过后至少隔 14 天进入自动复习，每轮最多选 2 条。日常提取重点是实际字形、合字和整词，而不是重复“什么是字母分类”式概念。

单元综合复习通常约 36 题，含所有补练最多 50 题。配对排除同音，但被排除的目标用单独题补齐；规则不用于凑数量。通用工厂限制单元最大目标数，避免未来新课程越过预算或漏覆盖。

额外课可在完成主线后自动开放，也可一次确认后提前解锁；提前练城市不替代学习 ঢ、合字等缺失先修，不解锁主线，不授予结课。进度、地图和 Rush 共用同一个开放判定。

## 字体、音频与地图

- `@fontsource/noto-sans-bengali` 的 400/500/600 字重随构建提供，OFL 原文在 `public/licenses/NotoSansBengali-OFL.txt`。完整文字节点保留附标和合字 shaping，不逐字符包裹 span。
- 不继承泰语字体切换、声调题、语音安装说明或占位组合器。
- 首版没有本地孟加拉语真人录音。只对显式整词配置 `bn` 设备语音或在线收听；无匹配语音时不使用英语声音朗读。字母、合字和占位附标不自动合成。
- 孟加拉国轮廓来自固定 Natural Earth v5.1.2 数据。浏览器只用预投影路径，不下载 GIS 库或在线底图。原数据、许可说明和改编 GeoJSON 在 `public/maps/`。
- 国名 বাংলাদেশ 以整国红面显示；城市用红点，不将同名 Division / District 混成同一个城市边界。

## 可复现维护

普通构建和测试完全不需要联网抓取资料：

```sh
npm run check
npm run test:e2e
```

重新获取逐词参考（需要已安装 Playwright Chromium；脚本在 Windows 使用现有 PowerShell 下载助手，缓存位于忽略目录 `.local/bengali-research/`）：

```powershell
$words = (Get-Content docs/BENGALI_WORD_AUDIT.json -Raw | ConvertFrom-Json).words.glyph
node scripts/audit-bengali-words.mjs @words
node scripts/build-bengali-audit.mjs
```

脚本优先读缓存；需要更新某词时先移走对应缓存 HTML。获取脚本提取词典证据，不生成课程 IPA；审校构建脚本在已有 IPA 与录入值不符时失败，必须人工查明原因。修改课程后应重新生成审校 JSON，并提交课程和审校表，保持测试一致。

地图重建：

```sh
node scripts/fetch-bengali-map.mjs
node scripts/fetch-bengali-map.mjs .local/natural-earth-countries.geojson
```

第一条下载固定版本，第二条可用已下载缓存离线重建。不要把 `.local`、浏览器缓存或测试截图提交进项目。

浏览器验收覆盖真实课程切换与答题、提前解锁取消/确认/刷新/课程隔离、词题与输入、字体像素、完整字形、国家与城市地图、320/390/1440px 的排版、五对匹配和 Rush。母语独立审读与授权录音仍是后续人工质量门槛。
