# 添加一种文字课程

原则：研究先于录入；课程内容、组合规则和界面元数据是数据，FSRS 和通用题型不需要按语言重写。

## 1. 研究包

为新课程先建立一份审校表，至少包括：

| 项目 | 必须记录 |
| --- | --- |
| 语言与书写系统 | 标准语/方言、文字方向、字形是否随位置变化 |
| 字音单位 | 字母、字母组合、音节、附标，而非机械按 Unicode 切分 |
| 转写方案 | 一套有来源的官方或权威规范拉丁转写，与 IPA 同时教；不另设自定义读音转写。明确国家官方、国际推荐和地图惯用名的区别 |
| IPA | 宽/严式、声调、重音、元音长短的取舍 |
| 形态变化 | 连写、上下标、独立/附属元音、尾音规则 |
| 来源 | 优先官方规范、大学课程、原始语言学研究与权威辞典 |
| 场景词 | 行政区划、主要城市、道路设施；逐词读音核查 |
| 音频 | 来源、说话人/口音、许可；无音频不得伪装已有真人录音 |

孟加拉文需考虑固有元音、元音附标、合字、尾部与固有元音脱落；阿拉伯文需考虑右到左、位置形、连接行为、短元音附标与常规不标元音文本。不能把泰文的占位替换模型直接认作这些语言的全部规则。

## 2. 一个课程文件

新建 `src/data/<course-id>.ts`，导出 `Course`。沿用现有 `thai.ts` 的数据工厂方式，但所有事实必须重新研究。必须填写：

```ts
import type { Course, Knowledge, Unit } from '../types';

// items 与 units 由已审定的教学事实组成，不能使用猜测的读音。
const items: Knowledge[] = [];
const units: Unit[] = [];

export const newCourse: Course = {
  id: 'your-stable-id',
  type: 'script',
  title: '课程中文名',
  nativeTitle: '本族文字名称',
  scriptName: '文字中文名',
  scriptClass: 'your-font-class',
  direction: 'rtl', // 或 ltr；只作用于实际文字，不翻转中文界面
  locale: 'ar',     // 仅在核对了具体语言后设置
  englishTitle: 'SCRIPT NAME',
  iconGlyph: '一个代表字形',
  label: '课程短标签',
  description: '课程范围',
  notationNote: '转写、IPA 和变体的明确边界',
  romanizationName: '实际采用的规范名称',
  romanizationSource: '规范来源 ID', // 必填，须在 sources 中存在
  ipaNote: '本课程 IPA 的取舍，如是否省略声调',
  referenceNotes: ['本课程自己的范围、转写约定与音频边界'],
  pronunciationReference: '发音资料的来源 ID', // 可选；须在课程 sources 中
  onlineListening: { label: '在线听本语言', language: 'ar' }, // 可选，只有显式原文会被带到 Google 翻译
  // voiceHelp: 'thai', // 仅泰语配置；其他语言不继承泰语安装说明
  // 有字体变体时才配置；第一项为默认，不要求每种语言都有两种字体。
  scriptVariants: [
    { id: 'print', label: '印刷体', className: 'your-font-class' },
    { id: 'other', label: '另一字形', className: 'your-other-font-class' },
  ],
  items,
  units,
  sources: [],
};
```

代码块是结构模板，**不是可发布课程**；空课程不能通过课程验收。

## 3. 知识记录

- `id`：全项目唯一、发布后稳定。
- `courseId`：课程 ID。
- `kind`：`consonant`、`vowel`、`symbol`、`rule`、`word`、`number`。
- `glyph`：完整的书写单位，可以是字母组合，不必是单个字符。
- `roman`：唯一教学转写，必须直接采用已核对的官方或权威规范。泰语用 RTGS，孟加拉语用联合国推荐 UNGEGN；无统一国家官方方案时如实注明，不能自创方案再称官方。IPA 课程使用发音特征名称，不伪造转写。载体声母的空转写显示为“不写”。
- `ipa`：所有辅音、元音、合字及有独立音值的附标必须同时给出已核对音值，不能只教拉丁转写；无读音的规则、数值可为空。没有独立音值的组合附标（如鼻化符号）可记为 `symbol` 并将 `ipa` 留空，但须解释所改变的音值、在完整词内给出带鼻化的 IPA，不能伪造辅音音值。字母转写保留的历史区别不等于现代实际音值的区别。
- `officialRoman`：旧扩展兼容字段，不再用于第二栏；如保留必须与 `roman` 相同，不能一栏教学转写、一栏规范转写。
- `explanation`：初见所需说明，特别写清上下文条件、反例和局限。
- `sources`：在本课程来源表中确实存在的 ID。
- `requires`：真实先修知识，不仅是表面出现的字符。
- `segments`：可选的、人工核对的词内结构；`reading` 使用与 `roman` 同一规范，不引入另一套读音提示。转写和实际发音的差异用 IPA 或 `note` 明确，不靠字符替换推断。
- `aliases`：输入可接受别名，只添加真的合理变体。
- `conventionalNames`：地图等语境中的惯用拉丁名称，与主转写分别展示，也可输入匹配；不把它们误标成规范方案。
- `pronunciation.recording`：可选的真人录音，包含本地 `src`、`title`、`sourceUrl`、`author`、`license`、`licenseUrl`；必须先核对音值与许可。语言词语、字母名称或例词另记 `spokenText`，与 `speech.text` 保持一致，保证本地录音、设备合成和在线收听是同一示范范围；共享例词可复用同一文件。
- `pronunciation.speech`：可选的 `{ text, label, lang? }`。必须显式指定可读原文和示范范围，例如“字母名：กอ ไก่”或“元音例词 กา”；单音条目的字母名、例词或字母组合必须在按钮/在线入口旁直接标明“非单音”，不能只藏在悬停提示里。不自动朗读字母/占位符/IPA。`lang` 缺省取课程 `locale`，没有同语言声音时隐藏扬声器，只保留配置过的在线入口；不使用英语声音代替。检测与排查放在学习首页。
- `extra`：主线语言的额外地名词设为 `true`，并归入 `extraUnits`。默认主线结课后开放；学习者也可在学习路径确认一次警告后提前解锁本课程。语言分支不是额外课，分支词不设 `extra`。
- `languageIds`：多语言文字课程中该知识适用的语言 ID；缺省仅属于 `mainLanguageId`。同形、相同教学音值的知识可归属于多个语言，只保留一条记录；同形异音须拆成不同稳定 ID。
- `branchId`：可选的语言分支归属；只放在对应 `branches[].units`，不进入主线、自动补充课或 `extraUnits`。
- `place`：行政区 `{ type: 'region', regionId: '稳定的边界 ID' }`；城市 `{ type: 'city', coordinates: [经度, 纬度] }`。跨国地点另设 `mapId`，指向 `course.geographies[mapId]`；不设置时用默认 `course.geography`。不能把印度地名画在孟加拉国轮廓上。普通“山、村、道路”等成分词不伪造一个固定地点。

抽象规则使用 `rulePrompt`、`ruleAnswer`、3 个 `ruleChoices` 表达一个已审定的判断；这属于知识编写，而不是在出题组件中插入语言分支。

规则只需一次无提示正确判断，不要求伪造反向题或重复刷概念。把同一事实在实际词里的应用写入 `requires`、`explanation`、`segments`；不要把需要不断练习的字母、附标或真实词错误标成 `rule` 来减少题数。已通过规则的自动复习至少间隔 14 天，每轮自动选择最多 2 条，每条只检查一次，答错最多补 1 题；手动指定规则仍可主动复习。应用层延迟不篡改底层 FSRS 卡。

每个知识恰好归入所属学习路径的一个目标单元：主线、额外课或语言分支。主线先修在主线阶段中位于其前方；分支内部先修在本分支中位于其前方。允许同单元后续知识依赖前面知识，出题器等先修完成练习后再引入。分支可引用主线先修作为默认已具备的知识，但不补写成绩。初期就解释后面使用的术语；若课程不深入教授某知识，明确边界与出处，不能在题中又要求掌握它。

**所有地名额外课每个单元目标约 10 个地名，允许 8–12 个。** 按地理或书写结构分组，不再建立一组 3 城或一组十几到几十城的单元。额外课在工厂中自动受此限制；分支地名课另设 `placeLesson: true`，同样校验数量及每词地图。词汇批次（通常每小课至少 6 个）和地名单元不是一回事，一单元可拆成多个小课，最后综合复习。

## 4. 可选的组合生成

没有审定组合语法时，**不配置** `composition`。双向题、配对、词汇解锁与 FSRS 仍然工作。

当前受限组合器适用于已核对的“一个辅音替换一个占位符”的结构：

```ts
composition: {
  vowelIds: ['course-vowel-1', 'course-vowel-2'],
  excludedConsonantIds: ['course-context-dependent-letter'],
}
```

元音 glyph 必须恰有一个 `◌`，组合音值必须真能由声母音值和所记元音拼合。连写、合字、同化、固有元音脱落、重排、带尾音变形等若不能满足这些前提，必须改用人工审定的组合知识或单独经过测试的语言适配器，不能强行使用通用拼接。

## 5. 注册和字体

1. 在 `src/data/index.ts` 中导入并以 `prepareCourse(newCourse)` 加入 `courses`，国际音标基础固定为列表首项。通用工厂校验规范名称、来源和字母 IPA，并拒绝第二套教学转写；未分配的主线词汇汇总为末尾补充单元。`allItems` 从注册表自动展开。
2. 在 `src/main.tsx` 导入有许可且覆盖该文字的本地字体。
3. 在 `styles.css` 添加与 `scriptClass` 对应的字体样式和合适行高。
   泰语的两种字体只由其 `scriptVariants` 数据配置；其他课程不继承泰语字形、RTGS 或声调说明。连写文字应保留完整文本节点，不能为了对照或标记而逐字符拆成 span。
4. 用实际 `rtl` 文本检查字形、标点和拉丁转写的混排；已有字形展示节点设置了独立方向与语言，不翻转整个学习 UI。
5. 来源注册到 `src/data/sources.ts`，并放进课程 `sources` 列表。

课程切换器、备份 ID 校验、图鉴、双向题、复习与进度记录自动读取注册表。无需新增 CourseId 枚举或修改 FSRS。新语言不自动继承泰语的组合配置、声调类别或街景照片。

`learningPolicy` 在 `src/data/template.ts` 统一定义复习预算与规则频率，不允许课程各自复制调度分支。综合复习通常约 36 题，**包括补练总计最多 50 题**；优先覆盖实际知识，同音而无法入配对的目标用独立题补齐，再混入最多 16 个到期的实际知识和已学内容。保留真实词中的附标辨认和课程批准的组合练习。预留至少 6 个补练位置，不能把规则当填充题刷到最低题数。只有规则且尚无实际知识可混排的单元，允许短复习；有实际知识可用时，已通过且尚未到间隔的规则不强行重考。工厂要求每单元“非规则目标数 + 最多 2 条规则”不超过 44，确保最坏情况下仍可全覆盖并留出补练空间；超出请拆单元，补充词汇单元同样受限。

## 6. 验收门槛

```sh
npm run check
npm run test:e2e
```

此外为新文字补充：

- 同音异形、同形异音和条件变体测试，四选一每题必须有且仅有一个正确答案。
- 从零按真实答题流程走完所有阶段，不可依赖人工篡改进度解锁。
- 每个词的声母、元音、尾音、隐含知识、特殊分音节都在前置图里。
- 相同标签或相同声音不会在唯一对应配对中产生歧义。
- 每单元有显式综合复习，常规 30–36 题，含所有错题补练最多 50 题；纯规则且无实际知识可混排时不凑题数。尽量五对满配，目标全覆盖；主线有唯一结束判定，不把额外地名当作结课条件。
- 简单 Rush 至少有 6 个唯一标签，词汇 Rush 的释义不作答案标签；主线结课或确认提前解锁后，额外词自动加入。语言筛选作用于两个 Rush 模式，共享字形不重复，少于 6 项不能启动。
- 配对及 Rush 必须既可左起也可右起；同侧点击只切换/取消选中项，永远只有一个待匹配项。右起错配仍按左侧目标记录易错知识，不能反转进度归属。
- 宽窄屏字形不截断，附标不被行高裁掉，RTL 与数字混排不颠倒。
- 原生或可信审校者对全量内容的独立审读。尚未取得时，明确记录“待独立审读”，区分词典原有 IPA、转写加标准音值、推测和程序核查；不能把自动测试通过当成母语审定或宣称内容完美。
- 真实语言音频若尚未就绪，明确显示边界，不使用其他语言 TTS 充当该音。
- 图鉴/练习中的字形切换、RTL 的完整 shaping、音频停止/失败/无匹配语音，以及录音署名。

## 7. 已发布数据的变更

存档使用稳定知识 ID。修正读音或题型可以保留 ID；删除或改变知识含义属于迁移事项。当前 v1 对未知 ID 采用保护性拒绝读取，原始存档不被覆盖；新增已注册课程不影响旧 ID。正式删除知识前，应先增加显式版本迁移，而不是要求用户无提示丢失进度。

已有未完成练习在读取时用知识 ID 更新转写标签、输入答案及组合读音，不改变题序、正确项 ID、作答统计或 FSRS。此逻辑不含泰语 ID 分支。保留旧转写兼容输入时应使用 `aliases`，不要把旧方案再放回主教学界面。

旧版保存的超长单元复习会截短至 50 题，已确认的结果和统计不丢失；若已答超过 50 题，只保留当前待答题，完成后正常结算。这个预算兼容处理不回滚任何已完成进度。

## 8. 自动复用的扩展

- 单元末综合复习、到期混排、五对补位、转写输入、显式补充课、祝贺页均由通用引擎处理，不复制进语言文件。
- `recognition: { marks, distractors, prompt }` 可配置附标辨认。只在词中确实包含目标附标时出题；当前用于泰语调号，其他文字需要先审定语义。
- `extraUnits` 使用与主线相同的 `Unit`，独立记录末尾复习，每单元 8–12 个地名。`extrasOpen(course, state)` 统一处理主线完成和 `earlyExtraUnlocks[course.id]` 的提前解锁，学习路径、图鉴、详情与词汇 Rush 保持一致。`extra` 模式可跳过词条先修，不写入缺失先修、不解锁主线、不授予结课。分支的先修规则见下节，不能借用额外课解锁来表达分支。
- `geography: { country, outline, regions, projection, source }` 和 `geographies` 使用本地预投影路径，画布固定 `180 × 260`；`projection` 为 Mercator 的 `scale` 和 `translate`。一幅地图中的行政区、城市共用一套投影；跨国条目按 `place.mapId` 使用相应地图，全部点均应落在画布内。原数据和派生数据库的许可、署名、版本必须保留。其他投影需要先扩展类型与投影函数。
- 简单 Rush 自动读取字母、元音、音标与受限 `composition`；词汇 Rush 自动读取完整词条。统一通过读音、字形去重。若同音异义必须分别练，需扩展语境设计，不能直接让两个一样的正确选项同时出现。
- `completedUnitReviews`、`rushBest`、`earlyExtraUnlocks` 是 v1 存档的可选字段，缺省为空，不重置原知识或 FSRS。提前解锁只作用于对应课程，随备份导入导出，刷新后不重复警告，重置全部进度会清除。旧用户会看到新加入的说明和单元复习待完成。

孟加拉文的完整实现与研究边界见 `src/data/bengali.ts`、`docs/BENGALI_RESEARCH.md` 和逐词 `BENGALI_WORD_AUDIT.json`，可作为复杂附标与合字文字的示例，不是把其读音约定复制给其他语言的模板。

## 9. 共用文字与平行语言分支

使用通用 `Course.languages`、`mainLanguageId`、`branches`，不在 UI、FSRS 或存档中写孟加拉语/阿萨姆语 ID 特判。以后可同样表达西里尔字母主线与其他语言分支；语言 ID、转写规范与实际知识仍须独立核查。

```ts
mainLanguageId: 'main',
languages: [
  { id: 'main', label: '主线语言', locale: 'xx',
    romanizationName: '权威方案', romanizationSource: 'main-standard' },
  { id: 'branch-language', label: '分支语言', locale: 'yy',
    romanizationName: '该语言的权威方案', romanizationSource: 'branch-standard',
    ipaNote: '分支自己的音值约定',
    onlineListening: { label: '在线听分支语言', language: 'yy' } },
],
branches: [{
  id: 'stable-branch-id', title: '分支语言', languageId: 'branch-language',
  description: '在主线基础上学哪些差异',
  units: [
    { id: 'stable-unit-id', title: '差异入门', subtitle: '本单元范围',
      phase: '分支', items: ['branch-item'], note: '默认掌握主线；内部先修仍须遵守' },
  ],
}],
```

- **学习路径**：分支入口显示在地名额外课之后，但逻辑上与主线平行，不是地名课之后的解锁阶段。第一单元始终开放，未完成主线时显示提醒并可直接进入；之后只检查本分支前面的单元及综合复习。
- **默认先修**：`branch` 会话跳过主线先修检查，但严格遵守本分支先修。不跳过其他分支的先修；工厂拒绝交叉分支依赖及未来依赖。不会写入未学主线知识，也不会授予主线结课或提前解锁地名课。
- **独立完成**：分支与主线共用出题、FSRS、50 题上限与单元复习逻辑，但各自使用单元 ID。继续下一小课留在当前分支，全部完成后回路径，不跳回主线。分支词明确排除于 `eligibleWords` 和自动主线词汇补充。
- **共享与差异**：文字相同不足以共享；还要教学音值、转写和解释适用。相同内容设 `languageIds: ['main', 'branch-language']`，共享一条 ID、FSRS 和字形；同形异音使用不同知识 ID 与语言标签，反向题还要按字形去重。
- **图鉴多选**：`lib/languages.ts` 是唯一归属/筛选入口。选多语言取并集，共享项只出现一次；全不选显示空结果，不偷偷回退为全部。默认全选，类别计数、练习已学内容与两个 Rush 都使用同一范围。筛选不改变学习路径、到期复习或主线完成判定。
- **Rush**：分支知识无需解锁主线或地名课即可进入相应语言池；主线 `extra` 仍遵守原解锁规则。各语言子集分别存最高分，按稳定顺序规范化 ID；全选沿用旧课程/模式的纪录键。更换选择不会改变已启动的棋盘。
- **音频与标记**：原文节点按知识归属设置 `lang`；分支自己的规范名称、IPA 说明、语音与在线收听优先。分支语音缺失时不得回退到主线语言；只链接匹配的在线入口。共享非词汇条目仍遵守不自动朗读孤立字母的原规则。
- **存档**：`languageSelections` 是可选的按课程语言 ID 列表，支持空数组，随备份与刷新保留；未知或重复语言 ID 拒绝导入。旧存档缺字段时全选，不重置已学条目。`branch` 加入会话模式，暂停、刷新与备份仍可继续。

工厂校验分支/语言 ID、规范来源、知识归属、每个分支知识的唯一单元及内部拓扑。必须补测：从零完成整个分支而主线进度保持空白、提前进入、四种筛选组合、两个 Rush、子集纪录、同形异音选项、对应语音和跨国地图，以及桌面/手机的字形和溢出。
