# 地图展示与争议地区维护规则

制定日期：2026-11-07。适用于已有课程、后续课程、图鉴、详情、配对、Rush 及地图重建脚本。

## 用途与声明

地图只辅助语言文字学习和城市位置辨认，不作导航、测绘、法定边界判定或政治观点表达。语言、文字、国家、实际控制范围不是同一概念。

仅可能涉及争议地图的课程主页显示统一声明。地图通过 `Geography.requiresDisclaimer: true` 显式标记；`LearnPage` 检查 `course.geography` / `course.geographies`，其中任一地图有标记时显示一次。当前印度、巴以地图有标记，因此孟加拉语、希伯来语和天城文课程显示；泰语等无需声明的课程及无地图的 IPA 课不显示。声明只在课程主页，不插入字母规则、词义题或其他具体教学内容。

统一文案：

> 本课程所有地图均仅作语言学习与位置展示，不用于导航或判定领土归属。课程只教学语言文字与地理知识，不包含任何政治立场。边界与地名存在不同表述，图示不代表对任何争议主张的认可。愿世界和平，愿每一种语言都成为理解彼此的桥梁。

所有需要声明的课程共用以上基础文案，不另加印度、巴以等地区的专属说明。不能因同一幅地图同时是默认图和 `geographies` 项而重复提示。来源视角、版本与数据限制保留在来源资料和维护文档中，不扩展为主页声明；不在词汇练习中要求对主权问题作答。

## 印度轮廓

- 使用 Natural Earth **v5.1.2、1:10m、China POV** 的 `ne_10m_admin_0_countries_chn.geojson`，选择 `ADM0_A3_CN=IND`。
- 不再使用旧的默认 1:50m 实际控制轮廓，不采用 India POV。主线孟加拉语、阿萨姆语分支、新增天城文三个语言的印度城市均复用同一配置。
- 重建器校验固定输入 SHA-256，简化后验证中国主张范围的典型检查点不被纳入印度面、德里仍在面内；课程验收测试另外检查城市投影未超出画布。
- 来源是公开制图数据的中国视角图层，不是中国政府审定标准地图。保留这一限制，不冒称已经实现法定制图或逐段边界审核；有正式出版需求时须另行取得符合适用要求的审定图源。
- 脚本：`node scripts/build-india-map.mjs`。原始来源、版本、校验和、派生方法保存在 `public/maps/INDIA.txt`；派生数据库为 `public/maps/india.geojson`，显示路径为 `src/data/india-map.json`。

## 其他争议地区

1. 开工前识别源数据采用的视角，明确区分主张线、实际控制线和普通行政区线。不依赖文件名 `countries` 就认定数据无争议。
2. 保留中性位置名称、词条实际语言和可检索的地图惯用名。历史异名可标为检索别名，不据名称推断主权。
3. 将可能涉及争议的地图标记为 `requiresDisclaimer: true`，仅使用共用主页声明，不加地区专属段落。确有必要区分重叠主张时，可另建有来源的争议区几何，用中性色斜线阴影和图例表示；不能徒手描线，也不能用没有几何证据的任意阴影掩盖问题。
4. 没有可靠边界来源时，不发布貌似精确的断言。记录未决事项，选择有依据的范围示意或暂缓该地图。
5. 阴影、边界和底图不得遮挡目标城市点，也不得成为语言题目的答案或政治判断题。

## 城市点与坐标

- 城市是近似市区参考坐标 `[经度, 纬度]`，不是行政面、城市中心的法律定义或精确导航点。
- 保留 Mercator 的 `scale`、`translate` 与地图路径一致。尼泊尔城市必须使用尼泊尔地图，不能绘在印度轮廓上。
- 红点半径由 SVG 屏幕变换、`devicePixelRatio` 和 `visualViewport.scale` 共同补偿。详情点的填色直径为 8 个设备屏幕像素，紧凑图为 5 个；白色描边单独补偿。放大地图时轮廓与点间距离放大，点本身不跟着变粗。
- 相同显示器上页面缩放或触摸缩放不改变点的屏幕尺寸。不同显示器的实际物理毫米大小无法由浏览器可靠获知，不保证跨设备同一毫米直径。
- 不用固定 SVG 用户坐标半径代替屏幕半径；仅加 `vector-effect` 也不会固定圆的填色大小。

## 新课程验收

- 对照 `ADDING_A_COURSE.md` 检查地图视角、争议说明、地名和语言归属。
- 检查含有标记地图的课程主页仅显示一次共用基础声明，无地区专属段落；未标记课程不显示，具体练习均无声明。
- 保存可追溯来源、版本、许可、派生 GeoJSON 与重建脚本；字体许可与边界许可分别处理。
- 在窄屏和桌面检查轮廓、点和长地名；测试页面缩放、触摸缩放、动态像素密度及 resize。
- 检查所有城市使用正确地图且位于画布内。测试检查点只防已知回归，不能替代完整边界审校。
