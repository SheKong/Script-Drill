# 本轮审查与 Rush 设计

核对日期：2026-10-22。

## 审查结果与处理

1. 辅音一开始就带中/高/低类标签，但声调背景直到后半程才介绍；旧调号题又直接考降调、高调。现在第一单元先说明五调和辅音分类的含义，所有辅音以分类说明为前置。后面的四个调号改考在词里辨认符号，普通词汇也自动生成辨认题；完整声调计算与口语不是本课目标。
2. 每个发音控件重复呈现来源、无语音解释、备用链接和完整系统安装帮助。现在只显示可用的播放图标和在线收听；示范范围在 title 中，只有实际播放失败才显示错误。安装与检测集中到首页，支持 voiceschanged 和手动重查。
3. 旧配对至多四对，而且只从本次目标与两个到期条目中取，排除了词汇。现在目标优先、已学补位、尽量五对，词汇配转写和 IPA。字母和元音也能输入转写，每单元末尾另外有至少 30 题综合复习。
4. 旧结课条件只检查固定非词汇单元，之后 createSession 每次偷偷追加一个 readyWord，因此会出现多轮三四题的无名称尾课。现在未分配主线词汇集中到显式补充单元；主线完成条件包含知识和所有单元综合复习，完成即祝贺。
5. 地名和地图属于通用数据扩展：主线保留七个典型府名及曼谷简称，余下地名放额外课。保留所有旧知识 ID 与既有进度，不删除旧词。

## 为什么需要三格轮换

始终展示五个唯一且完整的对应。如果消掉 A 后只填左、右两个空位，而且两格不是一对，棋盘就不再是五个完整对应：至少有一个文字或读音找不到答案。因此，“只改两格”“新两格不成对”“一直五对可解”三者不能同时成立。

最小解决方式是允许另一侧一个既有格子参与：

1. 消掉左侧 A、右侧 A。
2. 从不在屏幕上的词池挑新 X，把 X 放到左侧空位。
3. 随机选一个非空右格 B，把 B 移到右侧空位，X 的读音放到 B 的原位置。
4. 三个发生变化的格子淡入，其他格子不动；棋盘固定五行，左右仍各五个唯一条目，集合完全一致。

所以旧空位是 X / B，必不成对。不能盯着刚消掉的两个位置连续点；新右答案也不总出现在同一行。错配扣一分且短暂冷却，阻止随机连点获得稳定收益。最近候选冷却减少过快重复，小池不足时回退到合法候选，六个唯一条目也不会死锁。

## 数据与计分

- 简单池：非历史字母、元音、音标，以及课程批准的声母元音组合。组合仅练拼读，不伪造含义。
- 词汇池：所有主线词；主线结课后纳入所有额外词，不要求逐个地名课先学完。
- 先按完整字形和显示读音去重，释义不参与答案消歧。
- 正确 +1，错误 −1，最低零分；两分钟墙上时间到期即结束，切后台不会暂停。未完成退出不更新最高分。
- 最高分按 `courseId:mode` 分开保存，备份可导入导出。Rush 不创建 FSRS 复习记录，不解锁知识。

## 地名核对与地图

新增行政区对照 77 个词典词条，宽式 IPA 去除声调、连音弧、非音节附标和不释放附标后核对；记录见 `THAI_PLACE_AUDIT.json`，可以运行 `node scripts/audit-thai-places.mjs` 更新。部分额外城市的英文词典没有完整词条，改查百科的泰语 IPA，并明确标记为次级来源；词典缺少整词的条目不能据此声称做过母语者审定。

地图使用 geoBoundaries THA ADM1 的固定版本、2017 年边界：76 府和曼谷特别行政区。原贡献者为 OpenStreetMap contributors / Wambacher，ODbL 1.0。共享拓扑简化后生成约 40 KB 的 SVG 路径，运行时不载入 GIS 库或请求底图。来源版本、署名、许可链接与改编数据库在 `public/maps/`。

城市点为约略市区坐标。所有地图是学习示意，不作为精确导航或法定边界依据。原生或语言专家的全量独立审读仍是正式发布前的验收项。
