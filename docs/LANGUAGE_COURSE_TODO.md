# GeoGuessr 语言文字课程 TODO

调研日期：2026-10-31。本文仅规划后续课程，不增加、删除或重排网页中的课程。

## 排序口径

第一指标是：**学到能认读路牌、地址和招牌中的地名后，能否显著提高游戏中的区域定位能力**，而不是语言使用人数、旅行实用性或仅凭字形猜国家的便利程度。

这是依据社区指南整理的产品判断，不是 GeoGuessr 官方排名，也没有声称取得了玩家胜率、出题概率或学习收益的统计数据。同一档内的相邻名次可随实测调整。

- 优先看本地文字承载的地名信息、缺少拉丁字母对照时的信息增量，以及从国家进一步缩小到地区的价值；覆盖范围和跨地区复用作辅助判断，学习成本只作次要取舍。
- 默认学习者已认识普通英文字母。因此使用拉丁字母的语言整体后置，但这些语言的地名后缀和拼读规律并非没有价值。
- 西里尔字母、希腊字母是独立文字系统，不能因为部分字形像拉丁字母就归入“已会读”的低优先级组。
- 文字不等于语言。共享字母的课程先复用字形层，再分别教授各语言的读音、地名成分与地图拼法。不要把“会俄语字母”当成已经学会乌克兰语或蒙古语。
- 地名课程的目标是“本地字形 → 可检索的地图名 → 地区”，不只是机械转写；标准转写、实际读音和地图惯用拼法必须分开。
- 世界地图、社区图、比赛图及移动规则会改变收益；下面以可移动、可阅读标牌的综合世界图为基准，不承诺适用于所有赛制。
- 街景覆盖会更新；某国家有街景，也不代表所有地图都收录它。开工前重新检查目标地图、覆盖范围和牌面语言，不能把本次排序当成永久覆盖名单。

社区依据：Plonkit 入门指南专门将学习字母表与读取路牌地址相联系；国家指南又反复使用地址、行政区名、地名和多语言标识缩小区域。[S01] 印度指南则说明，同一国家内部的文字分布本身就能提供区域线索。[S06]

## P0：主线优先

- [ ] **01. 西里尔文字核心 + 俄语地名识读。** 价值：极高。俄语区域跨度大，读出城市、州名、方向和地址，通常比只认出“这里使用西里尔文字”更有用。首版：字母和易混字、地名拼读、行政区/道路词、主要城市与地区的地图名。[S02]
- [x] **02. 泰文基础及现有地名课。** 价值：极高；项目已实现。泰国指南包含大量本地文字路牌、行政区和公路信息，现有课程方向值得继续投入。[S04]
- [ ] **02a. 泰文后续扩充。** 在现有课程上补县/区级地址、地名常见构词、实际牌面字体与缩写；先做真实牌面和地图惯用名核对，不另开一门重复的字母课。
- [x] **03. 孟加拉文基础及现有城市课。** 价值：极高；项目已实现。孟加拉国地址中的村、邮局、警务区和县等信息，是明确的区域定位线索。[S05]
- [ ] **03a. 孟加拉文后续扩充。** 补孟加拉国县、常见 Upazila/Thana 地址结构、县名与地图异拼；增加与印度孟加拉语地区的对照，不能把文字直接等同于国家。
- [ ] **04. 天城文：印地语地名优先。** 价值：极高。印度幅员大，识别文字只能先缩小范围；读出地址和城市名才进一步产生定位收益。首版：字母、元音附标、常见合字、数字、州名/大城市、地址层级。后续为马拉地语和尼泊尔语分别加语言模块，不套用同一套发音。[S06][S07]

西里尔核心之后的扩展仍属于 01 的后续工作，不是把同一套字母重复建设七次：

- [ ] **01a. 乌克兰语。** 补专有字母、与俄语不同的对应音、州名和城市新旧地图名。乌克兰指南直接使用 Є/Ї/І/Ґ 等字母及道路标识辅助辨别。[S03a]
- [ ] **01b. 蒙古语西里尔文字。** 补 Ө/Ү、常见地名和省级名称；蒙古指南明确指出西里尔文字与少量英文的并存，并利用地名标识定位。[S03b]
- [ ] **01c. 保加利亚语；塞尔维亚语/黑山语。** 各自建立语言模块，补专有字母与拉丁/西里尔双写地名；不要沿用俄语读音。[S17]
- [ ] **01d. 哈萨克语；吉尔吉斯语。** 补各自扩展字母和地区地名，俄语对照仅作辅助；指南指出当地语言与俄语共同出现，不能只收录俄语地名。[S03c][S03d]

## P1：下一批完整课程

- [ ] **05. 高棉文。** 价值：高。柬埔寨本地文字读不通时容易丢失地址与地方信息；但部分公路牌提供拉丁字母对照，不能夸大“所有地名都没有英文”。首版：辅音系列、元音附标、常见合字、数字、主要省市和地址词。[S08]
- [ ] **06. 韩文。** 价值：高。学习音节块的成本相对可控，城市/道/郡/区名可直接用于区域定位；也要教韩语实际读法和地图罗马化的差异，不能只拼孤立字母。[S09]
- [ ] **07. 泰米尔文。** 价值：高。在印度南部与斯里兰卡的文字及地址线索中都有用途；课程应包含两地的地名差异，避免看到泰米尔文就锁定一个国家。首版：附标、常见字形组合、主要地区/城市、街道和地址词。[S06][S10]
- [ ] **08. 僧伽罗文。** 价值：高。斯里兰卡的地名和方位信息值得直接读取；与泰米尔文及英文字段联合练习比孤立认字更贴近牌面。首版：基础字母、附标、常见组合、地区/城市及道路词。[S10]
- [ ] **09. 阿拉伯文：先做文字核心，再按地区分模块。** 价值：高但受双语标牌影响。突尼斯、约旦、卡塔尔等指南均包含阿拉伯文相关线索；能读地名比仅凭字形识国更有价值。首版：连写位置、常见地名词形、数字、无短元音地名与地图名对照。之后再决定国家模块的先后。[S11][S18]
- [ ] **10. 日文：假名 + 地名用汉字读法。** 价值：高，但建设量大。优先学假名、都道府县/城市、地址构成、地名常见读法；对已识汉字的中文用户，难点常是日语读法与地图名称对应，而不是重新学全部汉字。不要把完整日语识字量作为首版目标。[S12]
- [ ] **11. 希腊文。** 价值：中高。希腊文字独立成系；本地牌面字体与地图双写名值得系统学习，但常见双语标牌会降低新增信息量。首版：字母及组合、常见地名读音、地区/城市和道路词。[S13]
- [x] **12. 希伯来文。** 价值：中高。2026-11-01 已实现 14 单元主线与 10 城额外课，含常见无点词形、词尾字母、地图异拼及城市/街道词；来源及待独立审读边界见 `HEBREW_RESEARCH.md`。以色列指南说明希伯来文常与阿拉伯文、英文同牌，因此识字有用，但不应排在完全依赖本地文字的场景之前。[S14]

09 的边界：波斯语和乌尔都语不是阿拉伯语。它们可复用部分连写教学，但专有字母、发音和地名规则必须独立审校；是否投入完整课程先做目标地图验证。[S18][S19]

## P2：区域专项与既有能力扩充

印度指南明确列出了下列多种文字的区域分布。先认脚本可以缩小范围，但这些课程的验收仍应是读出真实地名，不能只做“这是什么文字”的选择题。13 至 18 的内部顺序是产品取舍，不代表存在可靠的玩家收益统计。[S06]

- [ ] **13. 卡纳达文。** 价值：中高。面向卡纳塔克邦等区域；首版聚焦地名、地址词，以及与泰卢固文字的混淆辨别。[S06]
- [ ] **14. 泰卢固文。** 价值：中高。面向安得拉邦、特伦甘纳邦等区域；独立审校实际读音，不直接复用卡纳达文的对应关系。[S06]
- [ ] **15. 马拉雅拉姆文。** 价值：中。面向喀拉拉邦等区域；先做常见地名、附标、合字和实际牌面识读。[S06]
- [ ] **16. 古吉拉特文。** 价值：中。面向古吉拉特邦等区域；可借用天城文课程的组织经验，但不能把字形当成简单去掉顶线后的天城文。[S06][S19]
- [ ] **17. 古尔穆基文 / 旁遮普语。** 价值：中。先覆盖印度旁遮普语地名；巴基斯坦 Shahmukhi 另用不同文字，不与本课程混教。[S06][S19]
- [ ] **18. 奥迪亚文。** 价值：中。奥迪沙邦等区域专项；首版先做能读取常见城市、县和地址的最小课程，再决定是否扩充低频字形。[S06]
- [ ] **19. 阿萨姆语 / 孟加拉文近亲扩展。** 价值：中，增量成本较低。复用孟加拉文基础，专门教授 ৰ/ৱ、语言对应音及阿萨姆地名；不能把孟加拉语读音原样搬过去。[S06][S19]
- [ ] **20. 老挝文。** 价值：中，覆盖敏感。老挝指南指出可玩的官方覆盖集中在有限城市，且部分地点有英语地名对照。首版只围绕目标地图里实际出现的城市、地址和数字，不先追求全国地名大全。[S15]
- [ ] **21. 藏文体系：先做不丹宗喀语地名专项。** 价值：中，范围较窄。不丹指南提到藏文与罗马字母在店招/标牌中并存。先做常见地名、地名词形和地图对照；宗喀语与藏语不能视作同一发音系统。[S16][S19]
- [ ] **22. 繁体汉字地名专项。** 价值：因人而异。对不识汉字者可大幅上调；对已识汉字的中文用户，优先补台湾地名与地图罗马化、香港/澳门的本地地图拼法，而不是重复基础识字。日本汉字地名仍归 10，不混为汉语读音课。[S12][S18]

## P3：拉丁字母类，整体后置

这些语言主要依靠已有英文字母识读能力，再学习独特字母、字母组合、地名构词与地图异拼。低优先级指新建“整套文字课”的优先级低，不是说国家线索或语言能力没有价值。下列次序依据指南中的字母/地名线索及本项目定位作判断。[S17][S18]

- [ ] **23. 越南语。** 先做地名音节、đ 与带附加符号的元音、常见行政区/道路词；不能只教去声调后的字形。
- [ ] **24. 土耳其语；阿塞拜疆语分别扩展。** 地名、ğ/ı/İ/ş/ç 等独特字母及组合，语言规则分别审校。
- [ ] **25. 波兰语、捷克语、斯洛伐克语。** 先做三者易混字母、地名后缀和地图对照，再决定是否分成完整课。
- [ ] **26. 罗马尼亚语、匈牙利语。** 分别做独特字母、字母组合、常见地区/城市和地名构词。
- [ ] **27. 芬兰语、爱沙尼亚语、拉脱维亚语、立陶宛语。** 地名结尾、地区词与易混语言对照，不能仅按“波罗的海/北欧”混教发音。
- [ ] **28. 北欧语言及冰岛语。** æ/ø/å/ð/þ 等字母、地名读法和地区词；按语言分模块。
- [ ] **29. 巴尔干拉丁字母语言。** 克罗地亚语、波斯尼亚语、斯洛文尼亚语、阿尔巴尼亚语等，重点是地方词和地名后缀；与 01c 的双文字模块共享地名数据。
- [ ] **30. 葡萄牙语、西班牙语及地区语言。** 重点从相似语言中读出道路/行政词和地名；如需要区域专项，再独立评估加泰罗尼亚语、加利西亚语、巴斯克语等。
- [ ] **31. 其他拉丁字母类。** 法语、德语、荷兰语，及印度尼西亚语、马来语、菲律宾相关语言、斯瓦希里语等，先做短的地名/地址词包，不默认新建完整字母课。

## 条件观察：暂不进入实施队列

这些候选不是因为字形不独特而后置，而是本次资料不足以支持其在目标地图中的稳定收益。**不声称它们完全没有街景**。开工条件：确认实际地图收录、可重复出现的本地文字地名，以及可核对的课程来源；满足后重新插入上面的排序，不必等 P3 全做完。[S01][S19]

- [ ] **格鲁吉亚文、亚美尼亚文。** 分别核查覆盖和目标图收录；确认后独立评估，不先按文字独特度给高排名。
- [ ] **埃塞俄比亚文体系 / 阿姆哈拉语。** 先核查可玩的实际地点、牌面语言和地图名对照，再评估整套音节字形的建设量。
- [ ] **缅甸文。** 核查实际覆盖与地图收录；可借鉴附标课程组织，但不套用泰文、高棉文或孟加拉文的读法。
- [ ] **塔纳文 / 迪维希语。** 先核查目标图中的重复出现机会和可读地名素材，再决定是否开发右到左课程。
- [ ] **提非纳文字 / 阿马齐格语。** 先证明目标图中本地地名识读的额外收益，而非只作为字形辨认补充。
- [ ] **传统蒙古文。** 不替代 01b 的蒙古语西里尔主线；先核查真实牌面与地区需求，再决定竖排适配。
- [ ] **爪夷文、波斯语、乌尔都语。** 作为阿拉伯文字体系的候选语言模块，分别核查目标地图收益和本地规范；不因共享字母就默认已覆盖。

## 推荐执行顺序

1. 维护已有泰文、孟加拉文；新增课程先做 **01 西里尔核心 → 04 天城文**。
2. 完成 01a 至 01d 的国家扩展；随后推进 P1。扩展与新课可按真实素材质量调整先后。
3. 再推进 P2，优先保证每课有足够真实地名和独立语言审校，不为“凑齐脚本”制作只有字母表的课。
4. P3 优先做小词包；条件观察组一旦获得可靠覆盖和素材证据，单独重排。

## 每门课程的开工与验收清单

- [ ] 记录目标地图、研究日期、当地语言及地图实际使用的地名拼法；不以文字唯一对应国家。
- [ ] 选定可追溯的规范转写；将实际读音、标准转写、地图惯用名分开，取得独立语言审校。
- [ ] 首版以高频路牌/地址/行政区词及主要地名为中心，再倒推所需字母、附标和合字。
- [ ] 至少覆盖字形辨认、真实地名识读、地图名反向对应和实际地址应用，而不是只认脚本。
- [ ] 任何转写输入都有普通键盘可输入形式；列明全部接受的拼法及通用省略规则，测试组合附标、旧别名和地图异拼。
- [ ] 处理本地数字、字体变体、连写/组合、方向和手机显示；新增素材保留来源、许可和版本。
- [ ] 用未在课程中出现过的真实牌面做迁移检查，记录是学会读地名，还是只记住了课程例词。
